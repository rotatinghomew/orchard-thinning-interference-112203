# 产地苹果拍卖的流拍证据与重挂保底

`资料/演练.json` 保存本地合成的业务记录，不含个人信息及实际企业数据。各资料集的字段、单位和有效范围见[资料格式](资料格式.md)。需要 Python 3.11.2，仅使用标准库，从项目根目录运行。

查看资料包的记录数量：

```sh
python3 inspect_packet.py
```

编译与测试：

```sh
python3 -m compileall -q inspect_packet.py auction tests
python3 -m unittest discover -s tests -v
```

## 挂牌决策证据工具

`auction` 包把历史挂牌台账整理成交易员每轮挂牌可核对的证据，共五个子命令
（`--as-of` 不给时默认资料包内最新可知时点）：

```sh
python3 -m auction inventory [--as-of 日期]      # 各入库批可重挂余量与扣减去向
python3 -m auction week 2026-11-09 [--as-of 日期] # 一周开拍的完整证据（含流拍与取消）
python3 -m auction ladder 混合果 [--as-of 日期]   # 分价格区间的成交可能、买家范围与净款
python3 -m auction plans [--plan P2] [--as-of 日期] # 挂牌方案评估与比较
python3 -m auction diff P2:混合@2026-11-10 P2:混合@2026-11-14  # 价差来源核对
```

### 分析口径

- **价格归一**：`delivered` 条款的底价、锤价、报价减去承运费，统一到库边净价；
  按等级组合（混合果/单一优级）分层，按交割周（周一起）分周列示。
- **库存扣减**：只有实际交割与已签收留货扣减可重挂重量；流拍、成交后取消、
  未开拍都不扣。部分结清只按实交重量入账，不当作标的全交割。等级复核自其
  可知时点起用于现行复核，已完成的交割与到账照原单可查。
- **流拍证据**：公开升价场的站立价只说明买家曾愿意出到至少这个价；密封仅
  结果场未揭封时流拍不等于无买家；未开拍不是开拍机会，有意留库不计入随机
  流拍。同一货流（流拍→重挂→拆并）里的同一买家不按独立需求重复计。
- **时点纪律**：所有证据按 `--as-of` 过滤，揭封确认和重挂成交只更新今天对
  需求的理解，不会填进第一次开拍日前的依据。
- **方案评估**：承诺口径只含买家书面兜底与可交付货量；同一买家该周各笔兜底
  共用限额，几个标的不能各自按“可成交”重复占用同一额度。历史模型支持的
  涨幅只用于比较待挂方案，且成交概率与净价在同一底价区间内联合取值，不跨
  区间各取最有利。样本不足时保留区间或标明无法比较。
- **价差核对**：`diff` 把两个标的（可带各自截至日）的价差归因到标的条件、
  样本选择（含重挂与场次规则）和有效出价三类来源。

`inspect_packet.py` 仍只读取资料包并列出记录规模；`tests/` 核对输入记录的
引用与格式，并覆盖上述业务口径。
